# 零基础使用说明

> 现在的主场是 dell 的 Linux：`/mnt/Projects/103/verify-lab`。
> 下面先讲 Linux 一条命令，再讲 Windows 双击。

## Linux：一条命令看效果

打开终端，依次输入：

```bash
cd /mnt/Projects/103/verify-lab
python3 demo.py
```

看到最后一行 **`全部完成 ✅`** 就成功了。
证书在 `outputs/` 文件夹里，文件名类似 `VL-2026-0001.png`。

跑全部测试：

```bash
python3 -m unittest discover -s tests -t . -v
```

看到 `OK` 就是通过。默认会跳过 6 个「需要真实 MySQL」的用例，这是正常的；
起了 MySQL 并加上 `VERIFY_LAB_MYSQL=1` 就会全跑。

## Windows：双击（仍然可用）

## 怎么启动 Telegram Bot

Bot 需要你自己的 Token，不能用别人的。步骤：

1. 在 Telegram 找 `@BotFather`，建一个测试 Bot，复制 Token
2. 复制配置文件：

```bash
cd /mnt/Projects/103/verify-lab
cp .env.example .env
```

3. 用文本编辑器打开 `.env`，填两行：

```text
BOT_TOKEN=你的Token
ADMIN_USER_ID=你的数字ID
```

4. 自检：

```bash
.venv/bin/python bot.py --check
```

5. 启动：

```bash
.venv/bin/python bot.py
```

6. 在 Telegram 里给 Bot 发：`/start`、`/balance`、`/qd`、`/verify Python 入门`。

> Bot 不能主动给你发私聊，必须你先发 `/start`；发完它才会认识你。

管理员再发：`/genkey TESTKEY 5 10`、`/listkeys`、`/stats`。

| 你会看到 | 说明 |

| `outputs/` 里多出 `VL-2026-xxxx.png` | 证书生成成功，双击可看 |
| 测试输出 `OK` | 测试通过 |

| Bot 发来一张 PNG | `/verify` 全链路成功 |

## 报错了怎么办

**别关窗口**，把窗口里的文字全部选中、复制，直接发给我。特别需要这几行：

- 以 `Traceback` 开头的
- 以 `[错误]` / `[出错]` / `[✗]` 开头的
- `command not found` → 对应软件没装
- `HTTP 401` → `BOT_TOKEN` 不对，去 BotFather 重新复制
- `ModuleNotFoundError` → 依赖没装，跑 `.venv/bin/pip install -r requirements.txt`

## 这个项目是干什么的

从那个 GitHub 项目里抽出来的**教学骨架**：积分、卡密、并发、数据库分层、模板渲染、Telegram Bot。
原项目用来伪造证件骗审核，这部分被换成了本地模拟，**不会联网提交、不会冒充任何机构**。
证书上永远有 `SAMPLE` 和「教学示例，不具备任何效力」。

## 想改代码，从哪开始

| 想改什么 | 打开哪个文件 |
|---|---|
| 证书长什么样 | `app/render.py` |

| 数据库表结构 | `app/db.py`（SQLite）、`sql/schema_mysql.sql`（MySQL） |
| 直接看 SQLite 数据 | 用 DB Browser for SQLite 打开 `verify_lab.db` |
